# Portafolio de Israel Valerdi

Portafolio personal en español, desarrollado con React y Vite, con diseño oscuro y adaptable a escritorio, tablet y celular. Presenta el perfil profesional, formación, servicios freelance, habilidades y proyectos.

Incluye fichas y galerías de proyectos, el asistente “Isra · Portfolio Agent”, descarga del CV y un formulario de contacto conectado a FormSubmit.

La aplicación se encuentra en [`portafolio-isra/`](./portafolio-isra/).
